# L01 i L04 — realistyczne timeboxy

**Czas to propozycja dydaktyczna**, a nie cytat z Google Docs Laba.

## Lekcja 01 — prosty chatbot online (120 min)

| Minuty | Zadanie | Warunek odbioru |
|---|---|---|
| 0–10 | Demo gotowego agenta i zakres projektu | Realny tool call albo oznaczone REPLAY |
| 10–35 | W1: Node/Git, coding assistant, zmiana i debug | działająca lokalna strona |
| 35–70 | W2: Next.js + Vercel AI SDK/OpenRouter, streaming | rzeczywisty strumień |
| 70–95 | W3: GitHub, Vercel, env i publiczny URL | link działa, płatne API wymaga dostępu |
| 95–110 | Bufor na diagnostykę | błędy jawne, brak podawania sekretów |
| 110–120 | Zapis rezultatu | link, commit i status testów |

**Warunek przed zajęciami:** prowadzący dostarcza sprawdzony starter z prawdziwym npm lockfile oraz uprawnionym kluczem i przetestowanym deployem. Bez tego nie deklarować, że 120 min jest wykonalne dla osób startujących od pustego komputera.

## Lekcja 04 — 8 narzędzi, ReAct, dashboard (120 min)

| Minuty | Zadanie |
|---|---|
| 0–10 | Wprowadzenie i schemat wejścia/wyjścia |
