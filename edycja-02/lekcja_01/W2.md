# L01 · W2 — Pierwszy wynik z OpenRouter we własnej aplikacji

**CORE: 20 min. Wymagane:** W1, klucz inference Laba, potwierdzony model fast. Efekt: karta wyniku, nie tylko puste okno czatu.

## Zbuduj

1. Asystent tworzy Next.js App Router + TypeScript w `workspace/moj-agent`. Zapisuje dokładne wersje zależności i lockfile. Instalacja wymaga internetu; nie deklaruj jej wykonania z samego polecenia.
2. Skonfiguruj `.env.local` aplikacji. `OPENROUTER_API_KEY` i mapa modeli wyłącznie na serwerze. Pomocniczy wzorzec HTTP: `reference/openrouter.mjs`. Przy użyciu AI SDK wybierz jawny provider OpenRouter.
3. Zbuduj ekran: zadanie, przycisk „Przygotuj wynik”, odpowiedź, model użyty, stan loading/error/success, przycisk STOP. Wklejanie pięciu maili będzie w L08 — dziś jedno pytanie.
4. Endpoint `/api/chat` przyjmuje tylko dozwolone pola i tekst do 8000 znaków. Sprawdza demonstracyjny token dostępu po stronie serwera przed wywołaniem modelu. Zwraca kontrolowane błędy; nie przekazuje surowych nagłówków czy odpowiedzi dostawcy do UI.
5. Użyj tego samego cennika i pytania co w baseline. To jeszcze kontekst w żądaniu, nie RAG ani trwała pamięć. Pokaż różnicę między tymi rzeczami.

## Polecenie do asystenta

```text
Wykonaj CORE tego pliku zgodnie z KONTRAKT_TECHNICZNY.md. Jedna aplikacja, serwerowy OpenRouter, jawna allowlista modeli, limit wejścia i odpowiedzi, timeout. Dodaj test pustego tekstu, błędnego dostępu i awarii adaptera. Nie dodawaj narzędzi zapisujących dane. Najpierw minimalny wynik; streaming dopiero po jego sprawdzeniu.
```

## Odbiór

Pytanie o Start daje odpowiedź; puste wejście → 400; brak/błędny token → 401 i ZERO wywołań OpenRouter; awaria → komunikat bez sekretu; zatrzymanie nie tworzy nowego żądania. W DevTools nie ma klucza OpenRouter. Zapisz faktyczny czas oraz model; koszt nieznany nie jest zerem.

**Ratunek:** wróć do jednego endpointu i jednego inputu. **STRETCH:** streaming z anulowaniem na serwerze; UI oznacza częściową odpowiedź, zamiast udawać zakończony wynik. Przerwanie nie gwarantuje braku opłaty za pracę już wykonaną.
