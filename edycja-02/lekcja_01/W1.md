# L01 · W1 — Punkt startowy: co już umie gotowe AI?

**CORE: 15 min. Efekt:** działające środowisko i zapisany punkt odniesienia. Najpierw przeczytaj START.md i KONTRAKT_TECHNICZNY.md.

## Zrób

1. Otwórz tylko edycję 2. Sprawdź Node 22+, Git i obecność konfiguracji bez wypisywania sekretów. Uruchom `npm test`, następnie `npm run preflight` w katalogu materiałów.
2. Wybierz jeden proces: obsługa zapytań, analiza ofert albo poranny raport. Proces referencyjny: fikcyjna firma **Kursowy Agent** z `data/fixtures.json`.
3. W wybranej gotowej aplikacji AI, bez prywatnych danych, podaj fragment cennika i zapytaj: „Ile kosztuje Start netto i brutto? Podaj źródło i braki”. Zachowaj rzeczywisty wynik. Poprawna odpowiedź: netto 490/mies.; VAT i brutto nieznane. Nie prowokuj celowo gorszego wyniku.
4. Zapisz w `artifacts/baseline.md`: aplikacja/model, data, dostępne funkcje, dokładny input, wynik, czas i jedna rzecz potrzebna Twojemu procesowi poza tą odpowiedzią. Oznacz ręczne czynności.
5. Stwórz katalog aplikacji `workspace/moj-agent`. Nie kopiuj całej pierwszej edycji. Ustal punkt odbioru: wynik w swojej aplikacji i bezpieczny publiczny link.

## Polecenie do asystenta

```text
Przeczytaj AGENTS.md i ten warsztat. Sprawdź środowisko bez odczytu wartości sekretów. Przygotuj plan jednej aplikacji Next.js App Router + TypeScript z serwerowym OpenRouter. Nie dodawaj jeszcze bazy, RAG ani wielu agentów. Zapisz kryteria testu i plik baseline.md bez wymyślania wyników.
```

## Odbiór

Node i Git działają; offline test ma wynik; brak klucza daje NOT RUN, nie PASS; baseline zawiera prawdziwy input i output; wiadomo, po co budujemy własny system. Nie twierdzimy, że sam upload pliku wymaga customowej aplikacji.

**Ratunek:** przy braku konta/API wykonaj baseline na przykładowych danych lokalnie i opisz brak; nie instaluj trzech asystentów. **STRETCH:** porównaj gotowy czat z gotowym trybem agentowym, uczciwie zapisując różnice w dostępnych narzędziach.
